SATVIK SARAO — KIDS VIBES WEBSITE

Files:
- index.html
- satvik.jpg

How to use:
1. Keep index.html and satvik.jpg in the same folder.
2. Double-click index.html to open the website.
3. To publish for free on GitHub Pages, create a GitHub repository and upload both files.
4. In GitHub: Settings -> Pages -> Deploy from branch -> main -> /(root) -> Save.
5. GitHub will give you a public website link.

The music buttons open YouTube searches rather than embedding copyrighted audio directly.
